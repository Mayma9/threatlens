## Acceptance criteria

- [ ] **Given** trained models, **when** the administrator opens the model list, **then** she sees each version with its task, algorithm, metrics and training date
- [ ] **Given** a model version, **when** the administrator activates it, **then** it becomes the only active version for its task and the next scoring uses it
- [ ] **Given** a non-admin user, **when** she tries to activate a model, **then** access is refused
