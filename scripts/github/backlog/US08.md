## Context

- Backlog item: **US08** (specification §12.6)
- Use cases: UC20
- Functional requirements: FR-08, FR-09

## Acceptance criteria

- [ ] **Given** a new or updated CVE whose affected product matches a watchlist item through its aliases, **when** the pipeline runs, **then** one alert is created with status NEW
- [ ] **Given** an existing alert for the same CVE and watchlist item, **when** the pipeline runs again, **then** no second alert is created
- [ ] **Given** an alert, **when** it is created, **then** it has a due date and the creation is visible in the alert history
- [ ] **Given** affected vendor names that match no alias, **when** the run ends, **then** they are listed for review

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
