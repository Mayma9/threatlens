## Acceptance criteria

- [ ] **Given** the go/no-go of the Sprint 1 baseline (T07), **when** the final M1 is trained, **then** it uses CVSS 3.x labels only, a time-based split and reports macro-F1 (indicative target ≥ 0.70 on the most recent period)
- [ ] **Given** a CVE without any CVSS score, **when** the pipeline scoring step runs, **then** a SeverityPrediction is stored with the model version and a confidence value
- [ ] **Given** the enriched CVE record, **when** the effective severity comes from M1, **then** it is labeled as predicted
- [ ] **Given** the secondary target (CWE), **when** its results are too weak, **then** M1 is limited to severity (risk R4) and the decision is documented
