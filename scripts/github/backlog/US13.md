## Acceptance criteria

- [ ] **Given** the training data, **when** M2 is built, **then** features are frozen at the CVE publication date and CISA ADP SSVC exploitation fields and later scores are excluded (leakage check documented)
- [ ] **Given** a time-based split, **when** M2 is evaluated, **then** PR-AUC and precision@k are reported and compared with the EPSS score of the same date
- [ ] **Given** a scored CVE, **when** an ExploitationPrediction is stored, **then** it includes the probability, the model version, the confidence, `epss_at_prediction` and `feature_cutoff`
- [ ] **Given** the priority score, **when** it is computed, **then** EPSS stays an input (M2 is an honest benchmark, not a replacement)
