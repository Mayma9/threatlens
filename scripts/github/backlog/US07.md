## Context

- Backlog item: **US07** (specification §12.6)
- Use cases: UC09
- Functional requirements: FR-07, FR-08

## Acceptance criteria

- [ ] **Given** the analyst, **when** she adds a normalized product (vendor, product) to the watchlist, **then** it is stored with a criticality from 1 (low) to 4 (critical)
- [ ] **Given** a watched product, **when** the analyst adds aliases (raw vendor, raw product names published by the CNAs), **then** they are stored and used for matching
- [ ] **Given** a criticality outside 1–4 or a duplicate product, **when** the form is submitted, **then** a validation error is shown
- [ ] **Given** the list of unmatched vendor names, **when** the analyst opens it, **then** she can turn a raw name into an alias of a watched product

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
