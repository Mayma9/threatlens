## Acceptance criteria

- [ ] **Given** past runs, **when** the administrator opens the monitoring page, **then** she sees each run with status, duration and per-source counts
- [ ] **Given** a FAILED or PARTIAL run, **when** she opens it, **then** the error message and the quality report are shown
- [ ] **Given** the administrator, **when** she starts a run manually, **then** a new run is created with her as trigger

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
