## Context

- Backlog item: **US06** (specification §12.6)
- Use cases: UC14, UC17
- Functional requirements: FR-17, NFR data quality

## Acceptance criteria

- [ ] **Given** a run, **when** it starts and ends, **then** its status (RUNNING, SUCCESS, PARTIAL, FAILED), start and end dates and trigger (scheduler or user) are stored
- [ ] **Given** each source task, **when** it ends, **then** extracted, loaded and rejected counts, a JSON quality report and the error message (if any) are stored
- [ ] **Given** the quality checks, **when** a row breaks a rule (duplicate CVE id, CVSS outside 0–10, EPSS outside 0–1, unknown foreign key), **then** it is rejected and logged with its reason
- [ ] **Given** a failing source, **when** the run continues, **then** the other sources are processed and the run is PARTIAL

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
