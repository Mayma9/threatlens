## Acceptance criteria

- [ ] **Given** the ATT&CK and CTID connectors, **when** the pipeline runs, **then** techniques, groups, malware and CVE ↔ technique mappings are loaded
- [ ] **Given** the binary group × technique matrix, **when** M3 runs (Jaccard distance, hierarchical clustering), **then** each ThreatGroup receives a cluster_id and the silhouette score is reported
- [ ] **Given** an APT group, **when** the analyst opens it, **then** she sees its aliases, techniques, malware and the groups of the same cluster
- [ ] **Given** a few clusters, **when** they are reviewed with the supervisor, **then** the qualitative review is documented

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
