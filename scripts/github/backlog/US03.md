## Context

- Backlog item: **US03** (specification §12.6)
- Use cases: UC07
- Functional requirements: FR-04

## Acceptance criteria

- [ ] **Given** a CVE identifier, **when** the analyst searches it, **then** the matching vulnerability is shown
- [ ] **Given** filters on vendor, product, severity, KEV status and publication period, **when** they are combined, **then** only matching vulnerabilities are listed, paginated
- [ ] **Given** no result, **when** the search runs, **then** an explicit "no result" message is shown
- [ ] **Given** the target dataset (~300,000 CVEs), **when** a search runs, **then** the page responds in less than 2 seconds

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
