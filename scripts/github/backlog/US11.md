## Context

- Backlog item: **US11** (specification §12.6)
- Use cases: UC04, UC05
- Functional requirements: FR-09, FR-10, FR-11

## Acceptance criteria

- [ ] **Given** open alerts, **when** the analyst opens the list, **then** they are sorted by priority score (effective severity, exploitation likelihood, KEV presence, asset criticality, with documented configurable weights)
- [ ] **Given** filters on status, product, severity and KEV, **when** they are applied, **then** the list is filtered accordingly
- [ ] **Given** an alert, **when** the analyst changes its status (NEW, IN_PROGRESS, FIXED, RISK_ACCEPTED, FALSE_POSITIVE), assignee or adds a comment, **then** the change is saved
- [ ] **Given** a status change, **when** it is saved, **then** an AlertStatusChange records old and new status, author, date and optional comment

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
