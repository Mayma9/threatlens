## Context

- Backlog item: **US14** (specification §12.6)
- Use cases: UC06, UC03
- Functional requirements: FR-12

## Acceptance criteria

- [ ] **Given** open alerts, **when** the analyst prepares the weekly plan, **then** she selects alerts for a period (start, end) and the plan records her as preparer
- [ ] **Given** a submitted plan, **when** the CISO approves it, **then** the approval date and the approver are recorded
- [ ] **Given** a submitted plan, **when** the CISO requests changes, **then** her comment is stored and visible to the analyst
- [ ] **Given** an analyst, **when** she tries to approve a plan, **then** access is refused

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
