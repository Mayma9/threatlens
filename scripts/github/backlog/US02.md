## Context

- Backlog item: **US02** (specification §12.6)
- Use cases: UC15, UC16 (and UC17, UC18 for these two sources)
- Functional requirements: FR-16, FR-17, FR-18

## Acceptance criteria

- [ ] **Given** the base connector interface, **when** a new source is added, **then** it only implements extract / transform / load and its mapping
- [ ] **Given** the CVE List V5 source, **when** `python manage.py run_pipeline --source cve` runs, **then** a raw snapshot is written to `data/staging/` and vulnerabilities, CVSS metrics (provider NVD / CNA / CISA_ADP) and affected products are loaded
- [ ] **Given** the CISA KEV source, **when** `python manage.py run_pipeline --source kev` runs, **then** KEV entries (date added, due date, required action, ransomware use) are loaded and linked to their CVE
- [ ] **Given** the same period, **when** the command runs twice, **then** no duplicate row is created (idempotent load)
- [ ] **Given** a run, **when** it finishes, **then** a `PipelineRun` and one `IngestionTask` per source are stored with status and extracted / loaded / rejected counts
- [ ] **Given** one failing source, **when** the pipeline runs, **then** the other source still loads and the run status is PARTIAL
- [ ] **Given** the scheduler, **when** the daily task triggers the `etl` service, **then** the pipeline runs without manual action
