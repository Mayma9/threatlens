## Context

- Backlog item: **US04** (specification §12.6)
- Use cases: UC08
- Functional requirements: FR-05, FR-06

## Acceptance criteria

- [ ] **Given** a CVE, **when** the analyst opens its record, **then** she sees the description, every CVSS score with its provider (NVD, CNA, CISA ADP), the EPSS score and percentile, the KEV entry, the CWE, the ATT&CK techniques and the latest ML predictions
- [ ] **Given** several scores, **when** the effective severity is computed, **then** the order NVD > CNA > CISA ADP > ML prediction is applied
- [ ] **Given** a severity coming from the ML model, **when** it is displayed, **then** it is clearly labeled as predicted, with the model version and confidence
- [ ] **Given** a missing source value (no EPSS, not in KEV…), **when** the record is displayed, **then** the field shows "not available" instead of an error

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
