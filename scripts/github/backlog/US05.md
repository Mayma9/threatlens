## Context

- Backlog item: **US05** (specification §12.6)
- Use cases: UC16, UC17, UC18
- Functional requirements: FR-15, FR-16, FR-17, FR-18

## Acceptance criteria

- [ ] **Given** the EPSS source, **when** the pipeline runs, **then** the EPSS score and percentile of each CVE are updated for the run date
- [ ] **Given** the NVD API 2.0 and an API key read from the environment, **when** the pipeline runs, **then** NVD CVSS, CWE and CPE data are loaded incrementally while respecting the rate limit (retries with backoff)
- [ ] **Given** the MITRE CWE catalog, **when** it is loaded, **then** each vulnerability is linked to its weaknesses
- [ ] **Given** ThreatFox and an Auth-Key read from the environment, **when** the pipeline runs, **then** indicators, malware families and threat types are loaded (metadata only, IOC values never visited)
- [ ] **Given** the administrator, **when** she disables a source or changes its frequency, **then** the next run respects it
- [ ] **Given** any of these sources, **when** it runs twice on the same period, **then** no duplicate is created

## Definition of Done

Merged through a reviewed pull request · tests and data-quality checks pass · README / data dictionary updated · runs in Docker · shown to the Product Owner.
